**Note on CKV_AWS_174 (TLS v1.2):**  
In all four resources the `viewer_certificate` block either is empty or sets only `cloudfront_default_certificate = true`. The default CloudFront certificate *does* support TLS v1.2, but the scanner flags these configurations. The most likely reason is that the check expects an explicit `minimum_protocol_version` argument (e.g., `TLSv1.2_2021`). The file provides no such explicit setting, so the finding is reported.
