The scanner evaluated the Terraform configuration for EBS volume encryption requirements.

1. **aws_ebs_volume.enabled (lines 3-8)**

   - Reason: The volume has `encrypted = True` (line 7) but no `kms_key_id` argument. CKV_AWS_189 requires encryption with a customer managed key (CMK); without `kms_key_id`, the volume uses the default AWS managed key, which does not satisfy the rule.  
   - Remediation: Add a `kms_key_id` argument set to the ARN of a customer managed KMS key. Insert `kms_key_id = "<CMK ARN>"` after line 7, before the closing brace.

   - Reason: The volume explicitly sets `encrypted = False` (line 21), disabling encryption. This violates CKV_AWS_3 and consequently CKV_AWS_189.  
   - Remediation: Change line 21 from `encrypted = False` to `encrypted = True`, and add a `kms_key_id` argument set to a customer managed CMK ARN after line 21.
