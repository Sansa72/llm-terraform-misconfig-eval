### 1. CKV_AWS_336 on `aws_ecs_task_definition.fail` (lines 45–87)
**Rule:** Ensure ECS containers are limited to read-only access to root filesystems.

**What triggered it:**  
The task definition contains two containers. The first container (lines 49–58) has `readonlyRootFilesystem = true`, but the second container (lines 59–68) does **not** set `readonlyRootFilesystem`. When omitted, the default is `false`, meaning the second container’s root filesystem is writable.

In the second container definition (around line 59), add `readonlyRootFilesystem = true` so that both containers enforce a read-only root filesystem.
