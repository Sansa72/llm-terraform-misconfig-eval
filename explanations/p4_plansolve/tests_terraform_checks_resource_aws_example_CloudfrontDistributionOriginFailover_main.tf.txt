### General notes
- **WAF association (CKV_AWS_68, CKV2_AWS_47):**  
  To pass both checks, you must create a WAFv2 Web ACL (or use an existing one) that includes the AWS managed rule group `AWSManagedRulesKnownBadInputsRuleSet` (which contains the Log4j vulnerability rule) and attach it to each distribution via the `web_acl_id` argument.

  Create an `aws_cloudfront_response_headers_policy` (or use an existing one) and reference its ID in the `response_headers_policy_id` argument of every cache behavior (including the default cache behavior).  
- **Custom SSL certificate (CKV2_AWS_42):**  
  Request or import a certificate in AWS Certificate Manager (ACM) in the `us-east-1` region, then reference its ARN in the `viewer_certificate` block using `acm_certificate_arn` and set `cloudfront_default_certificate = false`.  
- **Access logging (CKV_AWS_86):**  
  Create an S3 bucket for logs (with appropriate permissions) and add a `logging_config` block to each distribution specifying the bucket and an optional prefix.
