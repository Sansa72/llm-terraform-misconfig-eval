The scanner flagged multiple encryption misconfigurations across your three `aws_emr_security_configuration` resources. Below is a breakdown of each finding, why it matters, and exactly what to change.

---

### General Principles

- **CKV_AWS_351 – Enable in‑transit encryption**  
  Data moving between EMR cluster nodes, or between the cluster and S3, must be encrypted to prevent eavesdropping and tampering. This is controlled by `EnableInTransitEncryption`.

- **CKV_AWS_171 – Use SSE‑KMS for S3 encryption**  
  S3 data at rest should be encrypted with AWS KMS keys (SSE‑KMS) rather than Amazon S3‑managed keys (SSE‑S3). KMS gives you control over key rotation, access policies, and usage auditing.

- **CKV_AWS_350 – Encrypt EBS disks**  
  EBS volumes attached to cluster nodes must be encrypted at rest to protect data if a volume is detached, snapshotted, or physically compromised.

- **CKV_AWS_349 – Encrypt local disks**  
  Ephemeral instance store disks must also be encrypted at rest for the same physical‑access protection.

### Resource `aws_emr_security_configuration.pass` (lines 1‑22)

**Findings:** CKV_AWS_351, CKV_AWS_171

**What’s wrong**  
- `EnableInTransitEncryption` is set to `false` – in‑transit encryption is completely disabled.  
- The S3 encryption mode is `SSE-S3`, which uses S3‑managed keys. The check requires `SSE-KMS` with a customer‑managed key.

**What is already correct**  
- `EnableAtRestEncryption` is `true`.  
- `LocalDiskEncryptionConfiguration` is present with `EnableEbsEncryption: true` and a valid KMS key ARN. This satisfies both EBS and local disk encryption requirements (CKV_AWS_350 and CKV_AWS_349 are not flagged).

**Required changes**  
1. Set `EnableInTransitEncryption` to `true`.  
2. Change the S3 encryption mode from `SSE-S3` to `SSE-KMS` and provide a KMS key ARN (can be the same key used for local disks or a different one).

**Corrected configuration snippet:**

      },
      "LocalDiskEncryptionConfiguration": {

        "AwsKmsKey": "arn:aws:kms:eu-west-2:680235478471:key/27b6fd31-ca6d-4c71-8dca-06ebd0f94174"
