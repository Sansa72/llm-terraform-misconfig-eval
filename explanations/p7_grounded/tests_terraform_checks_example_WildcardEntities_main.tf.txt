**Resource definition (lines 28–35):**
```terraform

  minimum_password_length        = 15
  require_lowercase_characters   = true
  require_numbers                = true

  require_symbols                = true
  allow_users_to_change_password = true

```

1. **CKV_AWS_9 – Ensure IAM password policy expires passwords within 90 days or less**  
   The resource does not set `max_password_age`. Without this argument, the account’s password policy does not enforce password expiration. The check requires a value of 90 or fewer days.

2. **CKV_AWS_13 – Ensure IAM password policy prevents password reuse**  
   The resource does not set `password_reuse_prevention`. Without it, users can reuse previous passwords. The check expects a value (e.g., 24) to remember a history of passwords and block reuse.

**What to fix:** Add `max_password_age = 90` (or less) and `password_reuse_prevention = 24` (or another positive integer) to the `aws_iam_account_password_policy` block.
