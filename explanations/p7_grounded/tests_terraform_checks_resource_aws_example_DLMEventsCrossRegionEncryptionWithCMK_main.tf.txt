The scanner flagged two resources (`aws_dlm_lifecycle_policy.fail` and `aws_dlm_lifecycle_policy.fail2`) for missing encryption settings on cross-region copy actions. Here’s exactly what the findings mean and where the problems are in your code.

---

### 1. Resource `aws_dlm_lifecycle_policy.fail` (lines 2–37)

**Findings:**
- **CKV_AWS_253** – “Ensure DLM cross region events are encrypted”
- **CKV_AWS_254** – “Ensure DLM cross region events are encrypted with Customer Managed Key”

**Root cause:** The `cross_region_copy` block inside the `action` block has an **empty** `encryption_configuration` block.

**Evidence in the file (lines 23–25):**
```terraform
    action {
      name = "tf-acc-basic"
      cross_region_copy {
        encryption_configuration {}   # <-- empty block
      }
    }
```

**Why it fails:**
- **CKV_AWS_253** requires that cross-region copies be encrypted. The `encryption_configuration` block is present but empty; the `encrypted` argument is not set to `true`. By default, encryption is disabled, so the check fails.
- **CKV_AWS_254** requires that a customer-managed KMS key be used for that encryption. Because no `cmk_arn` is specified, the check also fails.
