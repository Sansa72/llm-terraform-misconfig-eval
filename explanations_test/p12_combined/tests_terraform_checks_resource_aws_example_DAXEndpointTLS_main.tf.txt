### 1. CKV_AWS_239 on `aws_dax_cluster.fail` (lines 1–11)

**Trigger lines:**  
Line 6: `cluster_endpoint_encryption_type = "NONE"`

**What is wrong and why it matters:**  
The cluster endpoint encryption type is explicitly set to `"NONE"`, meaning TLS is not used for the DAX endpoint. Without TLS, data in transit between clients and the DAX cluster is not encrypted.

**Change needed:**  
Set `cluster_endpoint_encryption_type` to `"TLS"` so that the endpoint enforces Transport Layer Security.
