**Remediation Briefing: RDS Security Misconfigurations**

The scanner flagged multiple checks against the RDS cluster and instance resources in the provided Terraform file. Each finding is addressed below in the order reported. For every check, the evidence is limited to the file content and the check description; no additional attack scenarios or impacts are assumed.

---

### 1. CKV_AWS_313 on aws_rds_cluster.pass (lines 1‑3)
- **What is wrong:** The resource does not set `copy_tags_to_snapshot`.  
- **Why it matters:** Snapshots will not inherit the cluster’s tags, making cost allocation, identification, and compliance tracking harder.  
- **Change needed:** Add `copy_tags_to_snapshot = true` inside the `aws_rds_cluster` block.

### 2. CKV_AWS_96 on aws_rds_cluster.pass (lines 1‑3)
- **What is wrong:** `storage_encrypted` is not set.  
- **Why it matters:** Data at rest is not encrypted, exposing it if the underlying storage is compromised.  
- **Change needed:** Add `storage_encrypted = true` to the resource.

### 3. CKV_AWS_162 on aws_rds_cluster.pass (lines 1‑3)
- **What is wrong:** `iam_database_authentication_enabled` is not set.  
- **Why it matters:** Without IAM authentication, database access relies solely on static credentials, which are harder to manage and rotate securely.  
- **Change needed:** Add `iam_database_authentication_enabled = true`.

### 4. CKV_AWS_326 on aws_rds_cluster.pass (lines 1‑3)
- **What is wrong:** `backtrack_window` is not set.  
- **Why it matters:** Backtracking is unavailable; you cannot quickly rewind the cluster to a previous point in time without a full restore, increasing recovery time.  
- **Change needed:** Set `backtrack_window` to a non‑zero value (e.g., `86400` for 24 hours).

### 5. CKV_AWS_327 on aws_rds_cluster.pass (lines 1‑3)
- **What is wrong:** `kms_key_id` is not set.  
- **Why it matters:** Encryption uses the default AWS‑managed key, which offers less control over key rotation, access policies, and auditing than a customer‑managed key (CMK).  
- **Change needed:** Provide a CMK ARN in `kms_key_id` (e.g., `aws_kms_key.rds.arn`).

### 6. CKV_AWS_325 on aws_rds_cluster.pass (lines 1‑3)
- **What is wrong:** `enabled_cloudwatch_logs_exports` does not include `"audit"`.  
- **Why it matters:** Audit logging for MySQL engine is not captured, hindering security investigations and compliance.  
- **Change needed:** Add `enabled_cloudwatch_logs_exports = ["audit"]` (or include other required log types).

### 7. CKV_AWS_139 on aws_rds_cluster.pass (lines 1‑3)
- **What is wrong:** `deletion_protection` is not set.  
- **Why it matters:** The cluster can be deleted accidentally or maliciously, leading to permanent data loss.  
- **Change needed:** Add `deletion_protection = true`.

### 8. CKV_AWS_324 on aws_rds_cluster.pass (lines 1‑3)
