### 1. CKV_AWS_50 on `aws_lambda_function.pass` (lines 1‑11)
- **What is wrong:** The resource does not contain a `tracing_config` block, so AWS X‑Ray tracing is not enabled.  
- **Why it matters:** The check requires active tracing to provide end‑to‑end visibility into function invocations and performance.  
- **Remediation:** Add a `tracing_config` block inside the resource and set `mode = "Active"`.

### 2. CKV_AWS_117 on `aws_lambda_function.pass` (lines 1‑11)
- **What is wrong:** No `vpc_config` block is present; the function is not attached to a VPC.  
- **Why it matters:** Without VPC configuration, the function cannot access resources inside a VPC and lacks network‑level isolation.  
- **Remediation:** Add a `vpc_config` block specifying at least `subnet_ids` and `security_group_ids` that place the function in the desired VPC.

### 3. CKV_AWS_116 on `aws_lambda_function.pass` (lines 1‑11)
- **What is wrong:** The resource has no `dead_letter_config` block, so no Dead Letter Queue is configured.  
- **Why it matters:** A DLQ captures failed asynchronous invocations, preventing event loss and aiding debugging.  
- **Remediation:** Add a `dead_letter_config` block with `target_arn` pointing to an SQS queue or SNS topic.

### 4. CKV_AWS_272 on `aws_lambda_function.pass` (lines 1‑11)
- **What is wrong:** The resource does not include a `code_signing_config_arn` argument.  
- **Why it matters:** Code signing ensures that only trusted, unaltered code is deployed to the function.  
- **Remediation:** Provide a `code_signing_config_arn` that references a valid `aws_lambda_code_signing_config` resource.

### 5. CKV_AWS_115 on `aws_lambda_function.pass` (lines 1‑11)
- **What is wrong:** The `reserved_concurrent_executions` argument is missing.  
- **Why it matters:** Without a function‑level concurrency limit, a single function can consume all available account concurrency, potentially impacting other functions.  
- **Remediation:** Set `reserved_concurrent_executions` to an appropriate integer value (e.g., 5) to cap concurrent invocations.
