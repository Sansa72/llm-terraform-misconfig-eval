## Remediation Briefing

Below are the failing checks in the order they appear in the scanner output, with the exact evidence from the file and the required change.

### 1. CKV_AWS_351 on `aws_emr_security_configuration.pass` (lines 1–22)
**What triggers it:**  
Line 15: `"EnableInTransitEncryption": false`  
**What is wrong:**  
The check requires in‑transit encryption to be enabled; the configuration explicitly disables it.  
**Remediation:**  
Change the value of `EnableInTransitEncryption` from `false` to `true` inside the JSON configuration.

### 2. CKV_AWS_171 on `aws_emr_security_configuration.pass` (lines 1–22)
**What triggers it:**  
Line 9: `"EncryptionMode": "SSE-S3"`  
**What is wrong:**  
The check requires S3 encryption to use SSE‑KMS; the configuration uses SSE‑S3.  
**Remediation:**  
Change the `EncryptionMode` from `"SSE-S3"` to `"SSE-KMS"` and add a `"AwsKmsKey"` field with a valid KMS key ARN (e.g., the key ARN already present in the `LocalDiskEncryptionConfiguration` block).
