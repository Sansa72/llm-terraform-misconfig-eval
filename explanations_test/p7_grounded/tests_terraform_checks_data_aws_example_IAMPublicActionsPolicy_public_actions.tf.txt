### 1. CKV_AWS_26 on `aws_sns_topic.some-topic` (line 1)

**What the check requires**  
All data stored in the SNS topic must be encrypted using a KMS key.

**What the file shows**  
```hcl
resource "aws_sns_topic" "some-topic" {}   # line 1
```
The resource block is empty. There is no `kms_master_key_id` argument, so the topic will use the default AWS-managed key for server-side encryption. The scanner interprets this as a lack of explicit encryption configuration, which violates the policy.

**Fix**  
Add a `kms_master_key_id` attribute referencing a KMS key (either a customer-managed key or an AWS-managed key alias) to make the encryption explicit. For example:
```hcl
resource "aws_sns_topic" "some-topic" {
  kms_master_key_id = "alias/aws/sns"   # or a custom CMK ARN
}
```

### 2. CKV_AWS_283 on `aws_iam_policy_document.fail` (lines 3–14)

**What the check requires**  
IAM policy documents must not grant permissions to the wildcard principal `"*"` (i.e., any AWS principal) without a restrictive condition.

**What the file shows**  
```hcl
data "aws_iam_policy_document" "fail" {   # line 3
  statement {
    actions = ["sns:Publish"]            # line 6
    principals {
      type        = "AWS"                # line 9
      identifiers = ["*"]                # line 10
    }
    resources = [aws_sns_topic.example.arn]  # line 12
  }
}
```
The `principals` block uses `identifiers = ["*"]` (line 10). This means **any AWS principal** (any account, any IAM user/role) is allowed to perform `sns:Publish` on the topic. There is no `condition` block to restrict who that `"*"` actually applies to. The scanner flags this as an overly permissive policy.

**Fix**  
Replace `"*"` with a specific set of allowed principal ARNs, or add a condition that limits access (e.g., `ArnEquals`, `StringEquals` on `aws:PrincipalArn`). If the intent is to allow only a particular AWS account, use the account ARN. If you must use `"*"`, you must pair it with a condition that restricts access, as shown in the `pass2` example later in the file.

**What the check requires**

If the second statement is intentional, you must attach a condition that limits access (e.g., `ArnLike`, `StringEquals` on `aws:PrincipalArn` or `aws:SourceArn`).
