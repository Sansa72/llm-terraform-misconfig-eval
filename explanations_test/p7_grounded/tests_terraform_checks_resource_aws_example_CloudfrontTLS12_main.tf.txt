### **Summary of common missing configurations across all distributions**
- **WAF attachment** (`web_acl_id`) – missing in every resource.
- **Origin failover** – every distribution has only one origin; none define an origin group.
- **Response headers policy** – no cache behavior in any distribution references a response headers policy.
- **ViewerProtocolPolicy** – all except `pass2` use `"allow-all"` in the default cache behavior.
- **Custom SSL certificate** – `fail`, `fail2`, `fail3`, and `pass` lack a valid ACM certificate ARN.
- **TLS version** – `fail`, `fail2`, and `fail3` do not enforce TLS v1.2 or higher in the viewer certificate.

Address each finding in the corresponding resource block to resolve the scanner alerts.
