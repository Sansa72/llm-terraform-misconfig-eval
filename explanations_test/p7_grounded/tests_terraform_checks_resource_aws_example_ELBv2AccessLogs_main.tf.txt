### Checks and their meaning

- **CKV_AWS_152** – Network/Gateway Load Balancers should have `enable_cross_zone_load_balancing` set to `true`.  
- **CKV_AWS_150** – All load balancers should have `enable_deletion_protection` set to `true`.  
- **CKV_AWS_131** – Application Load Balancers should have `drop_invalid_header_fields` set to `true`.  
- **CKV_AWS_91** – Application and Network Load Balancers should have access logging enabled (an `access_logs` block with `enabled = true`).  
- **CKV2_AWS_28** – Public-facing Application Load Balancers should be associated with an AWS WAF web ACL.
